# AION EV - บันทึกค่าชาร์จและคำนวณอัตราสิ้นเปลือง (White Edition) ⚡🚗

เว็บแอพพลิเคชันบันทึกและคำนวณอัตราสิ้นเปลืองค่าชาร์จรถไฟฟ้า สำหรับ **GAC AION EV (สีขาวมุก)** ออกแบบ Mobile-First เพื่อใช้งานบนมือถืออย่างสะดวกสบาย ตัวหนังสือใหญ่ชัดเจน อ่านง่ายในรถ พร้อมระบบรองรับ **การชาร์จไฟบ้าน (Home Charging)** เต็มรูปแบบ

---

## 🌟 ฟีเจอร์ใหม่ที่ได้รับการอัปเกรด:

### 1. 🚗 ธีมรถไฟฟ้า AION EV สีขาวมุก
- ตกแต่งธีม Clean Minimalist สีขาวสะอาดตา ผสานกับโทนสีฟ้าไฟฟ้า Cyan ของ AION
- รูปภาพรถ AION สีขาว และไอคอนแอป AION EV คมชัดระดับพรีเมียม
- รองรับทั้ง AION Y Plus, AION V, AION ES และ AION ทุกรุ่น

### 2. 📱 ตัวหนังสือใหญ่ ชัดเจน เหมาะกับแอปบนมือถือ (Mobile PWA)
- ปรับขนาดตัวอักษรให้อ่านง่าย สบายตา ไม่ต้องเพ่ง
- ปุ่มกดและช่องกรอกขนาดใหญ่ สัมผัสง่ายด้วยนิ้วมือ (Touch-friendly 52px+)
- รองรับการติดตั้งแบบ **PWA (Progressive Web App)** ลงบนหน้าจอมือถือ (Add to Home Screen) ทั้งบน **iOS (iPhone/iPad)** และ **Android** ใช้งานได้แบบเต็มหน้าจอเหมือนแอปแท้

### 3. 🏠 ระบบเก็บข้อมูลค่าใช้จ่าย "การชาร์จไฟบ้าน" (Home Charging)
- สลับเลือกประเภทการชาร์จง่ายๆ ได้ 2 โหมด:
  - 🏠 **ชาร์จไฟบ้าน (Home Charger)**:
    - **คำนวณจากหน่วยไฟ (kWh):** ระบุหน่วยไฟที่ชาร์จ ระบบจะคูณอัตราค่าไฟให้อัตโนมัติ!
    - **รองรับเรทค่าไฟ TOU:**
      - TOU Off-Peak กลางคืน/วันหยุด (~2.63 - 2.80 บาท/หน่วย)
      - TOU On-Peak กลางวัน (~5.20 บาท/หน่วย)
      - ค่าไฟเฉลี่ย / มิเตอร์ปกติ (~4.20 บาท/หน่วย)
      - กำหนดอัตราค่าไฟเองได้ตามต้องการ (Custom Rate)
    - **ใส่ยอดเงินโดยตรง:** ระบุยอดเงินตามมิเตอร์หรือบิลไฟได้ทันที
    - ปุ่มเลือกจุดชาร์จลัด เช่น Wallbox ที่บ้าน, สายชาร์จพกพาฉุกเฉิน, บ้านต่างจังหวัด
  - ⚡ **สถานีสาธารณะ (Public Stations):**
    - ปุ่มลัดสถานียอดนิยม: PEA Volta, PTT EV Station PluZ, EleXA, EA Anywhere, Evolt, Tesla Supercharger ฯลฯ

### 4. 📊 ระบบสรุปและการวิเคราะห์ข้อมูล
- **การ์ดสรุปด้านบน:** แสดงยอดรวมค่าชาร์จ พร้อมแยกย่อย `🏠 ไฟบ้าน (บาท / ครั้ง)` และ `⚡ สถานี (บาท / ครั้ง)`
- **อัตราสิ้นเปลือง (บาท/กม.):** คำนวณอัตโนมัติเมื่อระบุเลขไมล์สะสมรถ
- **ความประหยัด:** คำนวณเปรียบเทียบว่าประหยัดเงินกว่ารถน้ำมันไปกี่บาทต่อกิโลเมตร และสรุปยอดเงินประหยัดสะสม
- **กราฟวิเคราะห์:**
  - กราฟแนวโน้มรายเดือน (แบบแยกสี ชาร์จบ้าน vs สาธารณะ)
  - กราฟเปรียบเทียบสัดส่วนค่าใช้จ่าย **"🏠 บ้าน vs ⚡ สถานี"**
  - กราฟสถานีที่ใช้บริการบ่อยที่สุด
- **ตัวกรองประวัติการชาร์จ:** กรองดูเฉพาะ [ทั้งหมด | 🏠 ชาร์จบ้าน | ⚡ สถานี] พร้อมระบบค้นหาและเลือกเดือน

### 5. 💾 สำรองและกู้คืนข้อมูล (Backup & Restore)
- บันทึกข้อมูลลงใน LocalStorage ของเครื่อง ปลอดภัย เป็นส่วนตัว 100%
- ส่งออกไฟล์ **Excel / CSV** เพื่อนำไปคำนวณภาษีหรือวิเคราะห์ต่อ
- สำรองข้อมูลและกู้คืนด้วยไฟล์ **JSON**

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ (ง่ายที่สุดบน Windows)
- ดับเบิ้ลคลิกไฟล์ `start.bat`
- เบราว์เซอร์จะเปิดหน้าแอป `http://localhost:3000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
```bash
npm start
```
หรือ
```bash
node server.js
```

### วิธีที่ 3: เปิดบนมือถือเพื่อติดตั้งเป็นแอป (PWA)
1. เชื่อมต่อมือถือเข้ากับ Wi-Fi เดียวกับคอมพิวเตอร์
2. เปิดเบราว์เซอร์ในมือถือ แล้วพิมพ์ URL ที่หน้าจอคอนโซลแจ้ง (เช่น `http://192.168.1.X:3000`)
3. **ติดตั้งลงหน้าจอมือถือ:**
   - **iPhone (Safari):** กดปุ่มแชร์ (Share) ➡️ เลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
   - **Android (Chrome):** กดปุ่ม "ติดตั้งแอป" บนแถบด้านบน หรือแตะเมนูจุด 3 จุด ➡️ "ติดตั้งแอปพลิเคชัน"
